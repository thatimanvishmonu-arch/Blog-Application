# Blog Application

A full-stack Blog Application with user registration, login, dashboard, and blog creation features.

## Features
- User Registration and Login
- Secure Password Hashing
- Create and Publish Blogs
- Blog Dashboard
- Logout Functionality
- Responsive Web Interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Project Structure
- `backend/` – Server-side code
- `css/` – Styling files
- `js/` – JavaScript files
- HTML files – Frontend pages

## How to Run

1. Open the `backend` folder.
2. Run `npm install`.
3. Run `node server.js`.
4. Open the frontend in your browser.
